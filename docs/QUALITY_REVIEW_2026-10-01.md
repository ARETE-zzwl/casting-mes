## 改进与证据

| 项目 | 改动 | 验证 |
| --- | --- | --- |
| 身份绑定 | issuer + subject 绑定有效员工；请求调用者必须一致；管理员同时检查 scope 与 MES 角色 | 身份冒用、未绑定、停用账号、仅有 admin scope、正常仓管与管理员 |
| JWT | 默认 audience 为 casting-mes，可由部署配置指定 | 本地 JWKS + 真实 RSA 签名；错误签名、issuer、audience 和过期令牌拒绝 |
| 附件 | prod 不再静态公开 uploads；上传人/显式读者逐次鉴权，旧文件默认拒绝 | 匿名 401、跨用户 404、授权后可读、撤销后拒绝、旧文件拒绝 |
| 数据库 | 独立 PostgreSQL 迁移生成，修复 CLOB、UUID 函数和约束语法；三个工艺参数改用文本映射 | PostgreSQL 17.11 新库执行 V1–V96；H2 V92 升级保留长文本及旧导出任务；重复迁移无新增执行 |
| 任务顺序 | 同创建时间增加批次与工序排序 | PostgreSQL 订单首道派工和报工回归 |
| 异步导出 | 原子领取、租约、执行令牌隔离、最多三次中断恢复、SQL 超时 | 有效租约不抢占、已完成不重跑、过期可恢复、达到上限失败、8 个竞争工作者只领取一次 |
| 联合备份 | 停写备份、SHA-256 清单、新目录/新数据库恢复，不覆盖原数据 | H2 数据与附件恢复；拒绝已存在目标、占用中的数据库和被篡改文件；PostgreSQL 新库恢复后数量与附件校验一致 |
| 回归可靠性 | 工资测试使用独立上下文，避免月初时其他测试工价污染；模具测试按材质选任务，不依赖随机批次顺序 | 原工价、模具独占断言保留 |

最终 `mvn verify`：53 个测试类、114 项测试，0 失败、0 错误、0 跳过，后端 JAR 构建通过；其中包含真实 Modulith 模块依赖审查。独立 PostgreSQL 新库选定回归为 12 项通过，不等于全部后端测试均已在 PostgreSQL 上执行。
